# WashQ wireframes (Team 18, SWE 363-01, Milestone 3)

Medium-fidelity desktop wireframes for the KFUPM Dormitory Laundry Management System.
26 screens (W1–W26), each with annotations and its other states, linked as a clickable prototype.
Open `index.html` to start.

## Publish on GitHub Pages (about 5 minutes)

1. On github.com, click **New repository**. Name it `washq-wireframes`, set it to **Public**, and create it.
2. On the new repo page, click **uploading an existing file**, then drag in **every file in this folder** (all the `.html` files, `wireframe.css`, this README and `.nojekyll`). Click **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. Wait a minute or two and refresh the Pages settings. The link appears at the top, in the form
   `https://<your-github-username>.github.io/washq-wireframes/`
5. Open the link in a private/incognito window to check it works without signing in, then paste it into the M3 PDF.
